### Step 1: Push to GitHub (5 minutes)
```bash

git init
git add .
git commit -m "Job Aggregator Platform"
git remote add origin https://github.com/YOUR_USERNAME/job-aggregator.git
git push -u origin main
```

### Step 2: Deploy Backend to Render (5 minutes)
1. Go to https://render.com
2. New Web Service → Connect GitHub
3. Select `job-aggregator` repo
4. Auto-deploy happens!
5. Get URL: `https://job-aggregator-api.onrender.com`

### Step 3: Deploy Frontend to Firebase (5 minutes)
```bash
cd frontend
npm run build
firebase deploy --only hosting
```

Get URL: `https://job-aggregator-xxxxx.firebaseapp.com` ✅
